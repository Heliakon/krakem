# Security policy

Text that people enter in Krakem is processed locally and is not uploaded, but they paste its prompts into AI tools and save its CLAUDE.md into their projects. A change to `assets/prompt.js`, `assets/humanize-brief.js`, or `assets/downloads/CLAUDE.md` can therefore affect what an AI does on someone else's machine.

If you find a security issue, please report it privately with **Security → Report a vulnerability** on this repository instead of opening a public issue. Include the steps to reproduce it and the commit you tested.

Only the latest version on the `main` branch is supported.
