Podgląd pliku
  1. 1

    Skopiuj

    Kliknij Skopiuj cały plik. Nie musisz niczego zapisywać.

  2. 2

    Wklej

    Wklej go do Claude Code i dopisz: „Dodaj te zasady do mojego CLAUDE.md. Jeśli go nie mam, utwórz go z poleceniami budowania i testów. Wypisz sprzeczności, zamiast wybierać”.
    Dla wszystkich projektów podaj zamiast tego ~/.claude/CLAUDE.md.

  3. 3

    Sprawdź

    Rozpocznij nową sesję. Uruchom /context i sprawdź sekcję Memory files. Aby później znaleźć sprzeczności, uruchom /doctor prompt-audit (Claude Code v2.1.283 lub nowszy).

Korzystasz z czatu Claude? Wklej poniższe zasady pisania do instrukcji projektu. Dokumentacja konfiguracji Claude Code ↗

Skopiuj tylko zasady pisania
ZASADY PISANIA
Zaczynaj od odpowiedzi. Używaj konkretnych czasowników i znanych słów. Każde pojęcie nazywaj zawsze tym samym terminem.

W procedurach staraj się, by zdanie miało najwyżej 20 słów. Warunki i ostrzeżenia umieszczaj przed czynnościami. Rozdzielaj kolejne czynności; te, które muszą odbywać się jednocześnie, zostaw razem.

Zachowuj fakty, definicje, równania, jednostki, kod, cytaty, zastrzeżenia i niepewność. Porównuj poprawki ze źródłem, aby wychwycić pominięcia lub zmiany znaczenia.

Pisz w języku mojego zadania. Zachowuj styl autora. Pytaj, gdy brak informacji wpływa na poprawność odpowiedzi.
